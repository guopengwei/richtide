# Set catalog governance and commercial activation gates

Parent: [RichTide Retail Investor Platform Design](../map.md)
Type: wayfinder:grilling
Status: open
Assignee: unassigned
Blocked by: [Define entitlement, Analysis Credit, access, and billing state machines](014-define-entitlement-analysis-credit-access-and-billing-state-machines.md)

## Question

How are plan prices, included allowances, package rates, usage-pack sizes, currencies, taxes, expiry, promotions, contribution-margin evidence, approvals, activation, disclosure, supersession, and retirement governed without hard-coding unsettled commercial values?

## Resolution evidence

- Versioned catalog lifecycle and approval authority.
- Required P90 cost and full-utilization margin evidence.
- Customer disclosure, catalog-change, grandfathering, and rollback rules.
- Explicit commercial activation blockers and exception policy.
